# v0.9 Parser Ease-ins Implementation Plan

**Goal:** accept more real SysML v2 / KerML syntax without spurious diagnostics.

**Spec:** `docs/superpowers/specs/2026-09-24-v0.9-parser-easeins-design.md`

## Global Constraints

- ESM + `.js`; English only; parser never throws; all 151 existing tests stay green.
- Minimal semantics: parse and record; do not evaluate.

---

### Task 1: Model + tokenizer

- [ ] `ElementKind` adds `'other' | 'stakeholder' | 'actor'`; `RelationshipKind` adds `'exhibit'`.
- [ ] `Element` adds `modifiers?`, `defaultValue?`, `isConjugate?`, `keyword?`, `frames?`.
- [ ] Tokenizer `ONE` adds `'~'`.

### Task 2: Parser

- [ ] Prefix set `['variation','individual','ordered','nonunique','snapshot','timeslice','derived']` handled like `abstract`: consume (stacking), push to `pendingModifiers`, recurse `parseMember`; `makeElement` applies `modifiers`.
- [ ] Usage defaults: in `parseUsage` (and `parseParam`), after type/multiplicity accept `default = <expr>` or `= <expr>`; capture raw into `defaultValue`, then `;`.
- [ ] Conjugation: in the type position, optional `~` sets `isConjugate`; keep `typeRef` without `~`.
- [ ] `binding ab [: Type] bind a = b;` → `connect` relationship with `connector: 'bind'` (reuse `parseBind` shape).
- [ ] `GENERIC = new Set(['metadata','concern','allocation','calc','function','predicate','class','assoc','connector','struct','datatype','rendering','expr'])` → `parseGeneric`: `keyword [def] Name [: Base] [{…}|;]` (or usage), element kind `other`, `keyword` set, body parsed as members.
- [ ] `exhibit`: `[featureKeyword] name [: Type];` → usage child; else `<ref>;` → relationship `exhibit` (source = owner).
- [ ] `stakeholder` / `actor`: `name : Type;` → child elements of those kinds.
- [ ] `invariant`: like `require`/`assume` (constraint child). Extend `assert` to accept `constraint`.
- [ ] `frame <ref>;` → `owner.frames`. `satisfy <ref>;` inside a view (no `by`) → relationship `satisfy` (source = owner).

### Task 3: Views + validation

- [ ] `bdd`/`ibd`/`statemachine`/`activity`: stereotype for `other` = `el.keyword ?? 'other'`; requirement rows add `stakeholder` / `actor` (`kind: name : Type`).
- [ ] `validate`: skip `defaultValue`; `other`/`stakeholder`/`actor` `typeRef`s resolve normally; `exhibit` endpoints resolve.
- [ ] Tests `test/parse-easeins.spec.ts`; fixture optional.

### Task 4: Verify + merge

- [ ] Root tests, typecheck, build green; merge via `finishing-a-development-branch`.
- [ ] Update `docs/usage/sysml-syntax.md` (+zh) Not-supported list and add a short
  "Modifiers, defaults, KerML declarations" note; CHANGELOG.
