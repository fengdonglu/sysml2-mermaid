# sysml2-mermaid 文档

[English](index.md) | 中文

`sysml2-mermaid` 将 SysML v2 文本模型（`.sysml`）渲染为图表——形态为 Mermaid 外部图插件，另附 `sysml2svg` CLI、语言服务器与 VS Code 扩展。本页是文档入口；项目概览与快速上手见 [README](../README.zh.md)。
